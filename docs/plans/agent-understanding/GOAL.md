# Agent Understanding

Status: complete; owner-approved on 2026-08-18 and verified complete on
2026-08-19.

## Question

Can the focal character retain conflicting delivered official versions, use
the revised version as a public working stance under local pressure, and later
resurface the earlier version through a physical diary strongly enough to
prompt one ordinary archive recheck?

## Goal Result

Evolve the single `first_day` scenario from `first_day_v2` to `first_day_v3`.
The completed run must demonstrate source-linked memory traces, one explicit
official-version conflict, one public-counter stance, one diary-cued private
stance, one additional consultation, filtered focal presentation, inspectable
causality, and deterministic reproduction.

The authored timing, pressure, diary access, and opportunity to recheck remain
scenario inputs. The result is bounded evidence, not unconstrained emergence or
a model of human consciousness.

## Authorized Module 2 Slice

Agent Understanding owns:

- memory traces created from delivered observations;
- interpreted claims for the supported direct-resource and official schedule
  evidence;
- explicit conflict between official versions for one period;
- contextual stance for `public_counter` and `private_diary`;
- source-linked stance transitions;
- detached evidence for restricted policy input and development inspection.

It does not own objective truth, Official Record mutation, observation
delivery, action choice, world resolution, physical diary state, or observer
prose.

## Invariants

- `EventLog` remains append-only objective evidence.
- An undelivered version cannot enter Agent Understanding.
- Official publication remains separate from observation delivery.
- The physical handover remains separate from the official entitlement claim.
- Conflict or stance changes never mutate traces, observations, or versions.
- Public expression remains an attempted action resolved by the world.
- Diary access still requires location and simulated time.
- Private understanding never enters supporting-agent or institution inputs.
- The normal observer receives only deliberate focal projection data.
- Equal configured runs produce equal ordered detached evidence.

## Completion Criteria

- **AU-1 Memory traces:** Supported delivered evidence creates immutable,
  source-linked traces and interpreted claims.
- **AU-2 Conflict:** Delivered same-period official versions retain one explicit
  conflict without absorbing the direct-resource claim.
- **AU-3 Public stance:** Sufficient local protocol pressure selects delivered
  version two only while the focal character remains at the counter.
- **AU-4 Public action:** Focal policy selects revised speech from restricted
  stance input while resolution remains separate.
- **AU-5 Diary record:** The physical diary preserves the earlier delivered
  official schedule claim and source.
- **AU-6 Resurfacing:** A delivered diary read creates the bounded private stance.
- **AU-7 Recheck:** The private stance changes the next attempt and produces
  exactly one additional valid consultation.
- **AU-8 Boundaries:** Understanding creates no impossible knowledge, sharing,
  observation, or world consequence.
- **AU-9 Presentation:** The focal view explains encountered behavior while the
  inspector reconstructs complete causality.
- **AU-10 Reproduction:** Equal `first_day_v3` runs retain equal JSON-compatible
  history and the full repository check passes.
