# Official-Version Conflict

## Topic

Recognize the delivered three-packet and two-packet schedule versions as one
explicit conflict.

## Required behavior

- Version one and version two remain separate immutable traces.
- Their interpreted claims share the configured proposition and period.
- Their different asserted values create a reciprocal conflict relationship.
- The direct-resource trace remains a different proposition.
- Equal numeric values across different propositions do not create a conflict.
- Conflict creation mutates no observation, objective event, or Official Record
  version.

## Evidence

- A focused test delivers both official versions and observes one conflict.
- A focused test retains the direct-resource trace outside that conflict.
- A focused test proves source observations remain unchanged.
- A focused test proves an undelivered version cannot participate.

## Exclusions

- General claim comparison
- Partial or semantic conflicts
- Confidence effects
- Conflict resolution
