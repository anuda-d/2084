# Understanding Presentation

## Topic

Explain the bounded Agent Understanding behavior without leaking omniscient
state.

## Required behavior

- The normal view shows only versions encountered by the focal character.
- The normal view explains the pressure-sensitive revised statement.
- The normal view identifies the diary entry as an earlier perspective.
- The normal view explains the later recheck without transition identifiers.
- The normal view exposes no hidden Official Record version or rewrite timing.
- The inspector shows memory traces, interpreted claims, conflicts, stances,
  transitions, source observations, diary evidence, attempts, and outcomes.
- Presentation consumes explicit projection data rather than reconstructing
  cognition from raw observations.

## Evidence

- Normal-output tests forbid inspector-only identifiers and hidden operations.
- Inspector tests reconstruct the complete causal chain.
- The documented normal and inspector commands complete successfully.

## Exclusions

- Graphical UI
- General history browser
- Raw model reasoning
